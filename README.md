## 新增六组角色

青岚世家（Qinglan）、赤霄战族（Chixiao）、霜月仙门（Shuangyue）、朱金皇族（Zhujin）、碧水文姬（Bishui）、杏林女医（Xinglin）。每组10张：kid小童、teen少年、adult成人、elder老人、emperor帝后/帝皇，各自含F女版与M男版。示例：Qinglan_kid_F.png为青岚世家小童女版，Zhujin_emperor_M.png为朱金皇族帝皇男版。

六组是新增角色家族，按各自成人锚点保持同角色相貌连续；没有擅自映射到A-D四种标准脸相。CSV中的“脸相/角色”列会明确标明这一点。
